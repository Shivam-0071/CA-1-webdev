Project Title-
Simple Restaurant Menu

Project Description-
This project is a restaurant menu webpage created for my college exam. It displays four items: water, sparkling water, packaged water, and biryani.

Files Included-
h.html : Contains the basic structure of the webpage and the buttons.
c.css : Contains the CSS styling. It uses flexbox to arrange the food cards.
j.js : Contains the JavaScript function that updates the text on the screen when an order button is clicked.
